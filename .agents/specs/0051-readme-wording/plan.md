## 애매한 곳
- 맨 위 제목 문장은 앞서 예전 문장 유지로 정해서 바꾸지 않음, 본문의 같은 문장만 바꿈 (확인됨)
- 문장이 어색해지는 두 곳은 뜻을 유지한 채 조사만 다듬음: "중복과, 설정을 통한…" → "중복을 확인하고, 설정을 통한…", "규모가 작아, 규모가 큰" → "규모가 작아, 큰" (가정)
